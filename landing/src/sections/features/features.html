What the platform does

Zero decryption

IPsecGuard never asks for keys and never opens a payload. Everything it knows comes from headers, sizes and timing that an eavesdropper on the same link could also see. That is the point: it shows you what they see.

session keys required: none

NIST SP 800-77 compliance engine

Negotiated IKE parameters are checked against NIST SP 800-77: cipher, integrity, DH group, PFS and key lifetime. Each finding caps the score, so one weak choice can't hide behind good ones.

3DES + SHA-1 + MODP-1024 scores 41/100

Explainable AI (SHAP)

Every classification comes with SHAP values computed for that flow, so an analyst sees why the model decided, not only what it decided.

pkt_count +0.136, max_iat +0.128

Countermeasure simulator

Simulates MTU padding and adaptive padding on the captured flow, re-scores it, and reports the bandwidth each one costs. A fix is recommended only if confidence actually falls.

adaptive padding: −3.9 pp for 17% bandwidth

Executive and technical PDF reports

A one-page summary for leadership, and a full report for auditors with every finding, the SHAP evidence and the limits of what a passive capture can prove.

exported straight from the dashboard
